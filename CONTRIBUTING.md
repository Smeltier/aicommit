# Contributing to aicommit

Thanks for considering contributing to aicommit!

## Getting started

1. Fork the repo
2. Clone your fork: `git clone https://github.com/<your-user>/aicommit.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feat/my-feature`

## Development

- Run in dev mode: `npm run dev`
- Run tests: `npm test`
- Build: `npm run build`

## Commit messages

This project uses `aicommit` itself to generate Conventional Commits messages. Run `aicommit` to stage and generate your commit message before committing.

## Pull Requests

1. Make sure tests pass and the build succeeds
2. Update documentation if you changed behavior
3. Open a PR against `main` with a clear description of what and why
4. Link related issues if any

## Code style

- No comments in code
- Keep functions small and focused
- Follow existing project conventions

## Reporting bugs / requesting features

Open an issue with steps to reproduce (for bugs) or a clear use case (for features).
